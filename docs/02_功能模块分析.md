## 二、模块详细说明

### 2.1 Agent 层 (`src/open_storyline/agent.py`)

**职责**：构建和配置 LangChain Agent，处理对话流程

**核心组件**：
- `build_agent()`: 初始化 Agent，配置 LLM/VLM，连接 MCP 工具
- `validate_api_key()`: API Key 有效性验证
- `ClientContext`: 客户端上下文，包含配置、会话、目录等信息

**与其他模块交互**：
- 从 `config` 读取配置
- 通过 `MultiServerMCPClient` 连接 MCP Server
- 使用 `NodeManager` 管理节点工具
- 使用 `ArtifactStore` 存储会话状态

---

### 2.2 节点系统 (`src/open_storyline/nodes/`)

#### 节点管理器 (`node_manager.py`)
- 管理所有视频处理节点
- 维护节点依赖关系和优先级
- 检查节点执行前置条件

#### 核心节点

| 节点 | 文件 | 功能 |
|------|------|------|
| **LoadMedia** | `load_media.py` | 加载本地媒体文件（图片/视频） |
| **SearchMedia** | `search_media.py` | 在线搜索并下载素材（Pexels API） |
| **UnderstandClips** | `understand_clips.py` | 使用 VLM 理解视频内容、场景、情绪 |
| **SplitShots** | `split_shots.py` | 基于 TransNetV2 进行镜头分割 |
| **GroupClips** | `group_clips.py` | 根据主题和内容分组素材 |
| **GenerateScript** | `generate_script.py` | 生成视频脚本和旁白文案 |
| **GenerateVoiceover** | `generate_voiceover.py` | 调用 TTS 生成配音 |
| **SelectBGM** | `select_bgm.py` | 推荐并选择背景音乐，支持卡点 |
| **PlanTimeline/PlanTimelinePro** | `plan_timeline*.py` | 编排视频时间线、镜头顺序、字幕 |
| **RenderVideo** | `render_video.py` | 最终渲染输出视频 |
| **SpeechRoughCut** | `speech_rough_cut.py` | 基于 ASR 的口播视频粗剪 |
| **GenerateAITransition** | `generate_ai_transition.py` | AI 生成转场镜头 |
| **RecommendEffects** | `recommend_effects.py` | 推荐视频特效 |
| **RecommendText** | `recommend_text.py` | 推荐字体样式 |
| **ScriptTemplateRec** | `script_template_rec.py` | 推荐脚本模板 |

#### 节点元数据结构

每个节点通过 `_meta` 字段定义：

```python
{
  "node_id": "unique_node_id",
  "node_kind": "function_category",
  "priority": 0,
  "next_available_node": ["node1", "node2"],
  "require_prior_kind": ["required_kind1"],
  "default_require_prior_kind": ["default_required_kind"]
}
```

---

### 2.3 MCP 层 (`src/open_storyline/mcp/`)

#### MCP Server (`server.py`)
- 使用 FastMCP 框架构建 MCP 服务
- 管理会话生命周期
- 注册所有工具

#### 工具注册 (`register_tools.py`)
- 将节点系统注册为 MCP 工具
- 处理工具调用和响应

#### 中间件 (`hooks/`)
- `chat_middleware.py`: 聊天中间件，处理错误、进度、日志
- `node_interceptors.py`: 节点拦截器，注入媒体内容、TTS 配置等

#### 采样处理 (`sampling_handler.py`, `sampling_requester.py`)
- 处理 LLM/VLM 采样请求
- 支持自定义采样回调

---

### 2.4 存储层 (`src/open_storyline/storage/`)

#### 制品存储 (`agent_memory.py`)
- 存储节点执行结果（元数据）
- 支持按节点 ID 和会话 ID 查询
- 时间戳追踪最新结果

#### 会话管理 (`session_manager.py`)
- 管理会话生命周期
- 会话过期清理
- 缓存管理

---

### 2.5 技能系统 (`src/open_storyline/skills/`)

#### Skills I/O (`skills_io.py`)
- 加载和保存 Skills
- 技能序列化/反序列化

### 2.7 Web 服务 (`agent_fastapi.py`)

**功能**：
- REST API 提供会话管理、媒体上传、聊天接口
- WebSocket 支持流式对话
- 静态文件服务（Web 界面）
- 限流保护（Token Bucket 算法）
- 会话状态持久化

**核心路由**：
- `POST /api/sessions`: 创建会话
- `POST /api/sessions/{id}/media`: 上传媒体
- `GET /api/sessions/{id}/media/{mid}/file`: 下载媒体
- `GET /api/sessions/{id}/media/{mid}/thumb`: 获取缩略图
- `POST /api/sessions/{id}/clear`: 清空会话
- `WebSocket /api/sessions/{id}/chat`: 聊天接口

## 三、模块互联方式

### 3.1 数据流

```
用户输入 (自然语言)
    │
    ▼
Agent (LangChain)
    │
    ├─► 理解意图
    │
    ├─► 调用 MCP Tools
    │       │
    │       ▼
    │   NodeManager → 选择合适节点
    │       │
    │       ▼
    │   执行 Node (如 LoadMedia/UnderstandClips)
    │       │
    │       ▼
    │   ArtifactStore (保存结果)
    │
    └─► 生成响应
            │
            ▼
        用户看到结果
```

### 3.2 节点间依赖

节点通过 `require_prior_kind` 和 `default_require_prior_kind` 定义依赖关系：

```
UnderstandClips 依赖 LoadMedia (需要先有素材)
    ↓
GroupClips 依赖 UnderstandClips (需要先理解素材)
    ↓
GenerateScript 依赖 GroupClips (需要素材分组)
    ↓
GenerateVoiceover 依赖 GenerateScript (需要文案)
    ↓
PlanTimeline 依赖多个前置节点 (素材、文案、配音、BGM)
    ↓
RenderVideo 依赖 PlanTimeline (需要时间线)
```
