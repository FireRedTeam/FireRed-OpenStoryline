# FireRed-OpenStoryline 技术架构

## 一、项目概述

FireRed-OpenStoryline 是一个 AI 驱动的智能视频创作系统，将复杂的视频创作转化为自然直观的对话体验。该项目兼顾易用性和企业级可靠性，使视频创作对初学者和创意爱好者都变得简单友好。

### 核心特性
- 🌐 **智能素材搜索与整理**：自动在线搜索并下载符合需求的图片和视频片段，基于用户主题素材进行片段拆分与内容理解
- ✍️ **智能文案生成**：结合用户主题、画面理解与情绪识别，自动构建故事线及契合的旁白，内置少样本仿写能力
- 🎵 **智能推荐音乐、配音与字体**：支持导入私有歌单，根据视频内容和情绪自动推荐背景音乐并智能卡点
- 💬 **对话式精修**：支持快速删减、替换或重组片段，修改任意字幕文案，调整文字颜色、字体、描边、位置等视觉元素
- ⚡ **剪辑技能沉淀**：可一键保存为专属剪辑 Skill，记录完整的剪辑逻辑，实现高效批量生产

## 二、技术栈

| 类别 | 技术 | 用途 |
|------|------|------|
| **核心语言** | Python 3.11+ | 主要开发语言 |
| **Agent 框架** | LangChain | 构建智能 Agent 系统，处理工具调用和多轮对话 |
| **MCP 协议** | Model Context Protocol (mcp) | 工具调用标准协议，支持多模态上下文 |
| **Web 框架** | FastAPI + Uvicorn | 构建 REST API 和 WebSocket 服务 |
| **视频处理** | MoviePy + FFmpeg | 视频编辑、渲染和处理 |
| **音频处理** | librosa | 音频分析和处理，用于 BGM 卡点 |
| **语音识别** | funasr | ASR (自动语音识别)，用于口播视频处理 |
| **多模态** | VLM (视觉语言模型) | 视频内容理解和分析 |
| **配置管理** | toml + Pydantic | 配置文件解析和类型验证 |
| **存储** | 本地文件系统 | 素材、输出、缓存存储 |

## 四、架构优缺点分析

### ✅ 优点

1. **模块化设计**
   - 节点系统高度模块化，每个功能独立实现，便于维护和扩展
   - NodeManager 统一管理节点，支持依赖追踪和优先级排序

2. **标准化通信**
   - 基于 MCP (Model Context Protocol) 协议，工具调用标准化
   - 便于与其他 Agent 系统（如 Claude Code、OpenClaw）集成

3. **灵活的配置系统**
   - 使用 Pydantic + TOML 配置，类型安全且易于扩展
   - 支持环境变量覆盖，便于部署

4. **会话持久化**
   - 支持会话状态保存和恢复，用户体验良好
   - 会话隔离设计，适合多用户场景

5. **技能系统**
   - Skill 机制支持工作流复用，便于批量生产
   - 可沉淀专业剪辑经验

6. **多接口支持**
   - 同时提供 CLI、Web、Agent 三种使用方式
   - 适应不同用户群体

### ❌ 缺点

1. **依赖外部 API**
   - 核心功能（LLM、VLM、TTS、AI 转场）依赖第三方 API
   - 成本较高，且受外部服务可用性影响

2. **渲染性能**
   - 基于 MoviePy 的视频渲染在处理大文件或复杂效果时较慢
   - 缺少 GPU 加速支持

3. **测试覆盖**
   - 当前代码库缺少自动化测试
   - 重构风险较高

4. **错误处理**
   - 部分节点的错误处理不够健壮
   - 缺少完善的重试和降级机制

5. **文档**
   - 虽然有基础文档，但缺少 API 参考和开发指南
   - 新手入门门槛较高

## 五、配置管理

### 配置结构

```
Settings
├── developer: DeveloperConfig (开发模式)
├── project: ProjectConfig (媒体/输出目录)
├── llm: LLMConfig (大语言模型配置)
├── vlm: VLMConfig (视觉语言模型配置)
├── local_mcp_server: MCPConfig (MCP 服务器配置)
├── skills: SkillsConfig (技能目录)
├── search_media: PexelsConfig (Pexels API)
├── split_shots: SplitShotsConfig (镜头分割配置)
├── understand_clips: UnderstandClipsConfig
├── group_clips: GroupClipsConfig
├── script_template: RecommendScriptTemplateConfig
├── generate_voiceover: GenerateVoiceoverConfig
├── generate_ai_transition: GenerateAITransitionConfig
├── select_bgm: SelectBGMConfig
├── recommend_text: RecommendTextConfig
├── plan_timeline: PlanTimelineConfig
└── plan_timeline_pro: PlanTimelineProConfig
```

### 核心配置文件

- `config.toml`: 主配置文件，包含所有配置项
- 支持环境变量覆盖配置

## 六、部署架构

### 单机部署

```
用户
  │
  ▼
Web 服务器 (FastAPI + Uvicorn)
  │
  ├─ MCP Server (本地进程)
  ├─ LangChain Agent
  └─ 节点执行 (LoadMedia / UnderstandClips / ...)
      │
      ▼
  本地文件系统 (素材 / 输出 / 缓存)
```

### Docker 部署

项目提供 Docker 支持，可通过以下命令部署：

```bash
# 拉取镜像
docker pull openstoryline/openstoryline:v1.0.1

# 启动容器
docker run \
  -v $(pwd)/config.toml:/app/config.toml \
  -v $(pwd)/outputs:/app/outputs \
  -v $(pwd)/run.sh:/app/run.sh \
  -p 7860:7860 \
  openstoryline/openstoryline:v1.0.1
```
